Connect Dolphin

Choose an Emulated Wii Remote in Dolphin’s Controllers window.

  1. Open Alternate Input Sources, enable DSU Client, and add:
    Name: Quest2Wiimote
    Address: 127.0.0.1
    Port: 26760
  2. Open Dolphin’s user folder, then Config/Profiles/Wiimote. Copy the generated profile INI files into it.
  3. Configure Wii Remote 1 and load Quest - Wiimote + Nunchuk. Select DSUClient/0/Quest2Wiimote if needed.

Two players: load Right Wiimote for player 1 and Left Wiimote for player 2 instead. The Quest app must be focused before the DSU devices appear.

Right A → Wii ARight trigger → Wii BLeft grip → Nunchuk CLeft trigger → Nunchuk ZLeft stick → Nunchuk stickLeft stick click → Recenter pointer
